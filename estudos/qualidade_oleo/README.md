# ジャトロファ 収穫後品質 実験計画(qualidade do óleo)

**`plano.html` が本体。**ブラウザで直接開ける単一ファイル(外部依存は Google Fonts のみ)。

収穫 → 果肉除去 → 種子乾燥 → 保管 の各工程が、油の**酸価(AV)**にどれだけ効くかを
モザンビークの自社圃場で確かめるための計画書。前半は独習用の読み物、後半はそのまま
現場に配れる実験手順と SOP。

## 中身

| Part | 内容 |
|---|---|
| 0 | 要旨・3つの結論 |
| 1 | 教養編:加水分解と酸化、酸価とは何か、水分活性、劣化「線量」の考え方 |
| 2 | 文献編:分かっていること・空白 |
| 3 | 実験設計(実験 0 / A / A2 / B1 / B2 / C / D / E)、反復数、解析計画 |
| 4 | AV の測り方・機材リスト・滴定 SOP・品質管理・安全 |
| 5 | 日程・体制・JatLog での記録設計・現場 SOP(ポルトガル語) |
| 6 | 結果と打ち手の対応表、経済換算、リスク |
| 7 | 専門家との想定問答 |
| 8 | 用語集・参考文献 |

## 注意

- **これは `docs/` の外にある。**GitHub Pages では配信されない(現場アプリとは無関係)。
- 数値のうち 「暫定」 と記したものは文献から置いた仮の値。実験結果が出たら
  差し替える。**差し替えたらコミットメッセージに「いつ・何の結果で変えたか」を残すこと。**
- 参考文献はすべて抄録・検索結果ベース。着手前に文献 1・4・6・14 の全文を入手して
  数値と実験条件を確認する(本文 Part 8 末尾の注記を参照)。
